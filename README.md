# Corrida X

Projeto piloto de calendário de corridas de rua em São Paulo.

| Pasta | O que é |
|---|---|
| [`corrida-x-coletor/`](corrida-x-coletor/) | Fase 1: pesquisa corridas por região e monta a planilha-piloto e o `calendario.json` (Python, linha de comando e app web). |
| [`corrida-x-coletor/corredor/`](corrida-x-coletor/corredor/) | App do corredor: calendário, amigos, treinos, grupos e parceiros (um `index.html` com Firebase). |

Cada pasta é publicada como um projeto separado na Vercel (em *Root Directory*, escolha a pasta).
